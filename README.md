# เปิดตำนาน — ร้านสุ่มการ์ด (Card Gacha Shop)

เว็บไซต์ขายการ์ดสุ่ม (gacha) ที่รองรับการเติมเงินผ่านคิวอาร์โค้ดพร้อมเพย์, แชทตอบโต้ลูกค้าอัตโนมัติ และการตั้งค่าโปรไฟล์บัญชี — เขียนด้วย HTML/CSS/JavaScript ไฟล์เดียว ไม่ต้องมี backend หรือ build step ใดๆ

## ฟีเจอร์

- **สุ่มการ์ด** — สุ่มทีละ 1 หรือ 10 ใบ พร้อมอนิเมชั่นเปิดการ์ดและตารางอัตราการออกการ์ด (drop rate) ที่โปร่งใส
- **คลังการ์ด** — ดูการ์ดที่มี พร้อมกรองตามระดับความหายาก
- **เติมเงินด้วย QR พร้อมเพย์** — สร้างคิวอาร์โค้ดตามมาตรฐาน EMV ของพร้อมเพย์แบบ client-side
- **แชทตอบโต้อัตโนมัติ** — บอทตอบคำถามพื้นฐาน (วิธีเติมเงิน, อัตราการ์ด, ราคา ฯลฯ)
- **โปรไฟล์ & ตั้งค่า** — ตั้งชื่อ/อวาตาร์ผู้ใช้ ตั้งค่าหมายเลขพร้อมเพย์ของร้าน ดูประวัติธุรกรรม
- ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ผู้ใช้แต่ละคน

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือใช้ GitHub Pages เพื่อเผยแพร่:

1. Push โปรเจกต์นี้ขึ้น GitHub repository
2. ไปที่ **Settings → Pages**
3. เลือก branch ที่ต้องการ (เช่น `main`) และโฟลเดอร์ root
4. บันทึก แล้วรอสักครู่ เว็บไซต์จะพร้อมใช้งานที่ `https://<username>.github.io/<repo-name>/`

## ⚠️ ข้อควรทราบเรื่องการชำระเงิน

การสร้าง QR พร้อมเพย์ในโปรเจกต์นี้เป็นการทำงานฝั่งหน้าเว็บ (client-side) ตามมาตรฐาน EMV เท่านั้น **ยังไม่ได้เชื่อมต่อกับธนาคารหรือผู้ให้บริการชำระเงินจริง** การยืนยันยอดโอนจึงเป็นการยืนยันด้วยตนเอง (manual) โดยผู้ใช้กดปุ่มยืนยันเอง

หากต้องการใช้งานจริงกับลูกค้า ควรเพิ่ม backend เพื่อเชื่อมต่อกับผู้ให้บริการที่ได้รับอนุญาต เช่น:
- ระบบแจ้งเตือนการโอนเงินจากธนาคาร (bank webhook/callback)
- Payment gateway เช่น 2C2P, Omise, Beam, GB PrimePay

เพื่อตรวจสอบและยืนยันการชำระเงินโดยอัตโนมัติ ป้องกันการปลอมแปลงยอดเติมเงิน

## เทคโนโลยีที่ใช้

- Vanilla JavaScript (ไม่มี framework, ไม่มี build step)
- [qrcodejs](https://cdnjs.com/libraries/qrcodejs) — สร้างคิวอาร์โค้ดจาก payload พร้อมเพย์
- Google Fonts: Kanit, Sarabun
- `localStorage` สำหรับเก็บข้อมูลผู้ใช้ในเบราว์เซอร์
